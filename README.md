# MorePower

MorePower is a small isometric idle game about building the biggest electricity grid you can.

## Run

Open `project.godot` in Godot 4 and press **F6** or run the project with **F5**.

## How to play

- Choose a generator and click an empty diamond to build it.
- Generators produce electricity and earn credits over time.
- Lifetime earnings unlock solar, hydro, and nuclear generators.
- Buy grid upgrades to double the output of every generator.
- Progress is saved locally, with up to eight hours of offline production.

The save file is stored in Godot's `user://` data directory.
